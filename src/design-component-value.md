# 点数の項ごとの短期の変化と長期の寄与（v0.28.1 設計・一部実装）

目的: 変化が多いのに進みにつながらない所への行き直しを減らすための材料を、項ごとに測れるようにする。重みはデータが支えるまで変えない。

## 実装済み（v0.28.1）
- 選んだ手の項（novelty・discovery・leave・change・text・info・unc）の割合 w_t = 項 / 項の合計。
- その手の結果を w_t で配る: 短期＝画面が変わった、長期＝遷移の図の新しい辺・新しい画面。
- 集計: 項ごとの重みの合計と、各結果の割合（session_end の score_contribution）。前半・後半の項の割合（score_halves）。

## 未実装（次の段階）
- 計画の成功（目的の達成）・先の選択肢の増え方（到達できる未試行の手の数の増減）を、手から Horizon 手以内の結果として項に配る。
- 文字の変化の短期の結果（届くのが非同期なので、届いた時点で同じ手の項に配る）。
- 待つ手の成分のうち「静止までの時間（区切りの時間）」の不確かさ。
- 重みの見直しは、実機の記録で「短期は多いが長期の割合が低い項」が複数の実行で一貫したときにだけ、根拠を書いて行う。
