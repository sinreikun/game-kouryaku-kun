# 監査 v0.33.0（起動ツールの本体自動更新）

v0.33.0: 利用者の指示 t111u。毎回フル配布 zip を送り直す運用をやめ、同じ起動用 exe（`ゲーム攻略くん.exe`）を起動するだけで本体（`app\`）を自動更新する方式に切り替えた。起動ツールが公開リポジトリの `release/latest.json` を見て、必要なら GitHub Releases の `app-update-<版>.zip` をダウンロード → SHA-256 / サイズ照合 → `app.new` へ展開 → `app` と原子的に入れ替える。ネットワーク失敗時は既存本体があればそれで起動。`data\` は触らない。起動ツール自身は自動では置き換えない。Observation / Global Transform / P-7 / 学習・しきい値は変更なし。
