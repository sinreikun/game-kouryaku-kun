# 監査 v0.39.5（T5 並列観測器バス→Supervisor（全段そろい））

v0.39.5: **T5**。`GKK_PARALLEL_OBSERVERS=1` で `ObserverBus`: frame_diff（静止確定対基準）・noise / noise_gap（T3 併用時）を観測器ごとの順序を保って並列に実行、OCR の台帳結果も同じバスへ。結果はすべて SensorResult（台帳で元の手・frame・取得時刻に合流）。背圧で間引けるのは途中フレームだけ、静止確定は落とさず待つ（落とした数≠0 は Health FAIL）。deadline 超過は late。終了時 drain と `observer_bus`（観測器ごとの遅延 p50/p90・late・待ち行列・並べ替え）。台帳は同じ手・同じ観測器の二重オープンを対応違反にする。

| # | 項目 | 結果 | 根拠・対処 |
|---|---|---|---|
| 1 | ゲーム固有の情報を入れていない | 適合 | 画面・時間・件数の形式的な量のみ |
| 2 | 実機試験はシステムの動作だけを評価する | 適合 | プレイの上手さは合否にしない |
| 3 | 未知の画面でも探索を止めない | 適合 | 新部品の失敗はログのみで探索継続 |
| 4 | OCR の文字は観測 | 適合 | OCR の結果の意味は解釈しない |
| 5 | LLM は攻略の主体ではない | 適合 | 使わない |
| 6 | 能力は経験の積み重ね | 適合 | memory.sqlite の CommitTurn 経路不変（旧 memory は読むだけの扱いを変えない） |
| 7 | Profile は身体と接続条件 | 適合 | Profile 未変更 |
| 8 | 「賢く見えるように直す」をしない | 適合 | 観測器は既存の差分基準（detOpt.Diff）をそのまま使う。GT/Track 不変 |
| 9 | 自己監査 | 実施 | ThroughputT*Tests。本ファイル |
