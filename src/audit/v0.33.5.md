# 監査 v0.33.5（S2 Sensor Stack 契約 + Assembler 縦スライス）

v0.33.5（t115u「進めて」）: **S2 Sensor Stack** の契約面を追加する。`docs/s2-sensor-stack-contract.md` で Observation Bundle を定義し、既存 `StructuredObservation` / `GlobalTransformConfidence` / EntityLayer から **再計算なし** で Bundle を埋める `SensorStackAssembler` を入れる。旧観測経路・学習・GT / Track しきい値・P-7 / Explorer / Goal は未変更。PlaySession 置換なし。EntityExperience はスタブ印のみ。

**診断フラグ** `RuntimeFlags.AttachObservationBundle`（環境変数 `GKK_ATTACH_OBSERVATION_BUNDLE=1`）。**既定 OFF**。ON のとき Session が観測保存後に Bundle 要約を `observation_bundle` ログへ書くだけ（探索継続・学習は memory.sqlite）。UI トグルは本スライス対象外。GitHub Release / `release/latest.json` は更新しない（コード＋契約＋テストのみ）。
