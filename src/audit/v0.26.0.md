## 決めたこと
- 操作: 単独 13（W A S D・Num0〜Num7・Tab）＋斜め 4＋Num5×8方向・Num2×8方向・Num3×斜め4＝計 37（＋待つ）。Num8/Num9 なし。
- 名前: 論理キー名を名前順に + でつなぐ（旧版の DB の同時押しの名前と同じ規則）。button1〜9 の中立名を DB に残す。
- Profile 0.2.0→0.3.0: button9=Tab を追加し Tab を禁止キーから外す（Shift+Tab は常に禁止）。ユーザーの Profile は起動時に自動更新（退避 .upgrade-日時.bak・ログ profile_upgraded）。割当を変えていれば割当に触れず chords だけ足す。
- DB の旧い同時押し: 削除しない（来歴として残す）。読み込みで今の候補にない操作の遷移は使わない・並び（ActionSequence）も候補にない操作を含めば作らない。名前が一致する組（例 dpad_left+dpad_up, button2+dpad_up）は学びを引き継ぐ。
- 単独キー優先の門（wip）: 入れない。ランダムな 66 組がなくなり、同時押しは身体の条件として明示された 24 件だけなので、未試行の新しさで公平に扱う。
- 起動時の入力の診断: 全 37 操作の物理キー・VK・押す/離す計画（N キー Down→Up）・禁止の検査をログ input_action_table に記録。送れないものがあれば開始しない（input_action_table_failed＝健全性 FAIL）。
- Human Control: ON のときだけ小さな別の窓（8方向・テンキーの並び・Tab・待つ・同時押しのキー Num2/Num3/Num5 を押したままにする切り替え）。位置は ui-settings.json の human_window_left/top。手は通常の入力経路（Action Source=human）。
