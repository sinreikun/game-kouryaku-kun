# 監査 v0.33.6（S2 EntityExperience 付帯 + Kernel Bundle 正規観測面）

v0.33.6（t115u 続き）: Observation Bundle に **EntityExperience 実スナップショット**を付帯（スタブ廃止）。`SensorStackAssembler.FromStructured(..., entityExperience?)` が `EntityExperience.Snapshot()` を読むだけ（学習・しきい値・同一性 KEEP）。`TrackQuality` サイズビンは Bundle に載せない（人間診断のみ）。

**RuntimeKernel** は `ObservationBundleJson` があるときそれを **正規観測面**（`ObservationKind.Bundle`）として Experience に書く。Structured JSON は provenance.`legacy_structured_json` に残す。Session の学習経路（memory.sqlite / StructuredObservation）は不変。dual-append ON 時は Session が Bundle を組み立てて渡す（Attach フラグ OFF でも可）。既定フラグはすべて OFF。GitHub Release / `latest.json` は更新しない。
