# 監査 v0.33.4（Experience vNext dual-append UI トグル）

v0.33.4（t114u）: 実機試験で Windows 環境変数を手作業設定しなくても dual-append を試せるようにする。右側パネル「診断・開発（Experience vNext）」に「Experience vNext dual-append」チェック（**既定 OFF**）。`ui-settings.json` の `experience_vnext_dual_append` に永続化。上部バッジ・接続パネル・探索開始ログ・診断 zip の `summary.txt` で有効状態を確認可能。

**優先順位**（`RuntimeFlags.ApplyEffective`）: (1) 環境変数 `GKK_USE_EXPERIENCE_VNEXT=1` → 強制 ON（開発用）(2) UI トグル ON → ON（通常の実機試験パス）(3) それ以外 → OFF。有効 ON 時の挙動は v0.33.3 と同じ（`VNextDualAppend.Try`、失敗しても探索継続。学習は常に `memory.sqlite`）。S2 / GT / しきい値 / P-7 / 学習 / Bootstrap は未変更。

## 実機データ
- 操作: 通常の `ゲーム攻略くん.exe` → 右サイド「診断・開発（Experience vNext）」→「Experience vNext dual-append」にチェック → バッジが `vNext併記: ON（ui）` → 探索開始。
- 確認: ログの StatusText、診断 zip の `summary.txt` に `vnext_dual_append effective=True source=ui`、必要なら `experience-vnext.sqlite` の行が増えること。既定は OFF のまま。
- 環境変数 `GKK_USE_EXPERIENCE_VNEXT=1` は開発用オーバーライドとして残存（UI OFF でもプロセスは ON）。
