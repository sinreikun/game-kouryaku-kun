# 監査 v0.39.3（T3 自然変化モデル（注釈のみ））

v0.39.3: **T3**。`GKK_NATURAL_NOISE_MODEL=1` で画面（mode）ごと・区画ごとに入力なし区間（手と手の間・待つ手）の変化率と変化の周期を学ぶ。入力の手の変化した区画に『自然変化の候補／入力起因の候補／基準なし』の注釈（`noise_annotation`）。観測・学習の入力は変えない。終了時 `noise_summary`。

| # | 項目 | 結果 | 根拠・対処 |
|---|---|---|---|
| 1 | ゲーム固有の情報を入れていない | 適合 | 画面・時間・件数の形式的な量のみ |
| 2 | 実機試験はシステムの動作だけを評価する | 適合 | プレイの上手さは合否にしない |
| 3 | 未知の画面でも探索を止めない | 適合 | 新部品の失敗はログのみで探索継続 |
| 4 | OCR の文字は観測 | 適合 | 画面の区画の変化だけ。意味を解釈しない |
| 5 | LLM は攻略の主体ではない | 適合 | 使わない |
| 6 | 能力は経験の積み重ね | 適合 | memory.sqlite の CommitTurn 経路不変（旧 memory は読むだけの扱いを変えない） |
| 7 | Profile は身体と接続条件 | 適合 | Profile 未変更 |
| 8 | 「賢く見えるように直す」をしない | 適合 | 注釈のみで観測を消さない・GT/Track 不変。時間的≠因果（入力起因は候補） |
| 9 | 自己監査 | 実施 | ThroughputT*Tests。本ファイル |
