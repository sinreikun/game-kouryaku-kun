## 主な変更（v0.7.0 → v0.8.0）

- 遷移パターンの区切り: ExcursionDetector・TransitionPatternBook（方向入力に反応する種類の画面から離れて戻るまで）を削除 → SequenceLearner（連続経験履歴の n-gram 閉頻出系列・循環・予測の外れ／Page-Hinkley 変化点／変化量の外れ値を境界の候補とした区間）
- エピソード境界を与えない: 学習は experience_stream を seq の順にだけ読む。runs は実行単位（システム情報）としてだけ残す。learning_runs の見方を削除。再起動の切れ目に印を付けない
- anchor（入力に連動して動く点＝操作対象の前提）を列・計算とも削除。配置推定の領域名を Translating / FixedInTranslating に中立化
- DB v5: 区切り依存の表（transition_patterns・transition_pattern_stats・transition_events・run_end_features）削除、experience_stream・sequence_patterns 追加、v0.7.0 の中立キーの記録を履歴へ移行（診断・旧キー名は除外）
- システムの不具合修正（v0.7.0 の診断 zip で確認）: 「変化なし」待ち時間の打ち切りの偏り（遅い応答が標本に入らず下限 600ms に張り付く）→ 判定後の変化（late_change）を検出し下限の推定として標本に加える。Profile v1→v2 移行のログ記録。探索でも分離の数（前面・背面の手、背面中の UA 停止）を記録
- 診断 zip: 画像を入れない（入れようとすると失敗）、profile.json と健全性レポート health.txt / health.json を同梱
- 静的検査の追加: 系列の学習に run・episode・excursion・adventure・session の語がない、探索が学習器に実行単位を渡さない、履歴の読み出しが実行単位で絞らない、識別子に excursion・episode・anchor・adventure がない、診断 zip に画像を入れない

## 疑わしいもの・判断の記録

- 状態の記号には画面の種類とノード（枠の配置）を使う。これは汎用の視覚特徴による教師なしの識別で、意味は前提にしない
- 系列の記号に「画面が変わったか」を含める: 入力の結果の観測であり、意味付けではないと判断した
- 再起動・実行単位の切り替わりに印を付けないため、切れ目をまたぐ並びも系列として数えられる（指示どおり。区切りも経験から見つける）
- 境界の候補の統計の窓・倍率（窓 300 手、2.5σ／3σ、Page-Hinkley の λ=8・δ=0.5、n-gram 2〜6、最小回数 3）は汎用の値で、実機から決めていない
