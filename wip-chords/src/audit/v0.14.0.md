## 主な変更（v0.13.1 → v0.14.0）

- NoveltyConcentration（Core/Exploration/NoveltyConcentration.cs）: P(既に見た k) = w_k/(n+α)、P(まだ見ていない結果) = α/(n+α) をまだ見ていない画面で等分。α は「n 回見た関係で新しい結果が出たか」の尤度を最大にする値（対数で等間隔の 61 点から選ぶ）
- TransitionModel の予測（PTop・エントロピー・起きた結果の確率・外れの量）をこれに置き換え。従来は既知の画面の数 V だけ 1 回分ずつ足すラプラス平滑化で、V が増えるほど予測が薄まっていた
- 系列の学習の TransitionPredictor はラプラス平滑化のまま（置き換えると合成試験「遷移の表の入れ替わりを 20 手以内に見つける」の 3 回目の切り替えを見落とした。閾値を合わせて通すことはせず、今回は測って不具合が分かった内部モデルの予測だけを変えた）
- 健全性レポート: 「実行 #n の予測の確率と当たった割合」（10 段に分けた較正のずれ。0.15 を超えたら注意）。終わりのログに `novelty_alpha`
- 実機の確認の手順から、確認済みの「欄を畳む → 閉じる → 起動し直す」を外した
- DB スキーマは v9 のまま
