## 起動ツール（ゲーム攻略くん.exe）を作り直さなかったことの危険
v0.23.1 の zip の起動ツールは v0.23.0 で配った起動ツールとバイト単位で同じ（SHA-256 1b355faf930438fa28655713e762ff24c502db1400d222fdf6a16351ecb5361d）。ソース（launcher/*）も同じで、アプリの版を埋め込んでいない（埋め込んでいるのは起動ツール自身の版 0.4.0 と runtime-manifest だけで、変わっていない）。危険は小さい。残る危険は box の C++ の道具（g++・mingw-w64）がなく、起動ツールのテスト（test_core）を今回は流していないことと、次に起動ツールを変えるときは道具の入れ直しが要ることだけ。
